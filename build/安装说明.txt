MySQLStudio 安装说明
====================

系统要求
--------
- macOS 13 (Ventura) 或更高版本
- 兼容 Apple Silicon (M 系列) 与 Intel 芯片（universal 通用二进制）


安装步骤
--------
1. 双击 MySQLStudio-2.0.0-universal.dmg
2. 在弹出的窗口里，把 MySQLStudio 图标拖到右侧的 Applications 文件夹
3. 打开「访达 → 应用程序」，双击 MySQLStudio 启动


关于「无法验证开发者」
----------------------
本发布包已使用 Apple Developer ID 签名，并通过 Apple 公证（Notarization），
正常双击即可打开，不会出现「Apple 无法检查其是否包含恶意软件」的提示。

如果你是从源码自行构建、未做签名，首次打开需要：
  方式一：在「应用程序」里按住 Control 点击（或右键）MySQLStudio → 选择「打开」→ 再点「打开」
  方式二：终端执行  sudo xattr -cr /Applications/MySQLStudio.app


使用说明
--------
首次启动会显示连接界面，填写你的 MySQL 连接信息：
  主机：127.0.0.1（本机）或远程服务器 IP
  端口：3306
  用户名 / 密码：你的 MySQL 账号
  数据库：可留空
点「连接」即可。连接信息会记住，下次直接点连接。


功能速览
--------
【数据】表数据浏览 · 排序 · WHERE 筛选 · 双击单元格编辑 · 新增/删除行 · 导出 CSV/JSON/SQL
【库】数据库列表刷新 · 右键编辑字符集/排序规则 · 删除库 · 整库导出（结构 / 结构+数据）
【结构】列定义查看与编辑 · 添加/删除/重命名列 · 索引查看 · 外键管理（新增/编辑/删除）
【查询】Monaco SQL 编辑器（语法高亮 + 自动补全）· ⌘+Enter 执行 · 多结果集标签 · 历史记录
【字典】全库数据字典 · ER 关系图（卡片可拖动/重置）· 导出 HTML / Markdown / CSV
【其他】右键表可重命名/清空/删除/导出 SQL · 工具栏可导入 .sql 文件 · 双主题切换


常见问题
--------
Q: 连接失败提示 "Access denied"？
A: 检查用户名密码；MySQL 8 若使用 caching_sha2_password，本应用已支持。

Q: 中文显示乱码？
A: 应用已固定使用 utf8mb4 连接字符集，若仍有问题请检查库/表的字符集设置。

Q: 关系图卡片被我拖乱了？
A: 点工具栏「重置位置」恢复自动布局；重启应用也会重置。

Q: 想换主题？
A: 点标题栏右上角的月亮/太阳图标循环切换（暗色 → 浅色 → 跟随系统）。

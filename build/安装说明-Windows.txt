MySQLStudio 2.0.0 — Windows 11 安装说明
==========================================

一、安装
  1. 双击 MySQLStudio-2.0.0-win-x64.exe
  2. 若弹出「Windows 已保护你的电脑」（SmartScreen）：
     点「更多信息」→「仍要运行」。
     （安装包未购买 Windows 代码签名证书，属正常提示，不是病毒）
  3. 选择安装目录（默认装到当前用户目录，无需管理员权限）→ 下一步 → 安装
  4. 安装完成后自动启动；桌面和开始菜单会生成 MySQLStudio 快捷方式

二、系统要求
  · Windows 11 / Windows 10 1809 及以上，64 位
  · Windows on ARM 设备可直接运行（系统自带 x64 模拟）
  · 首次启动会请求「专用网络」以外的出站连接（MySQL 数据库），无需放行入站端口

三、数据与配置
  · 连接配置（含密码）保存在：
    C:\Users\<用户名>\AppData\Roaming\MySQLStudio\connections.json
  · 卸载程序不会删除该文件，重装后连接信息仍在
  · 若要彻底清理：卸载后手动删除上述 MySQLStudio 文件夹

四、卸载
  设置 → 应用 → 已安装的应用 → MySQLStudio → 卸载
  或：控制面板 → 程序和功能 → MySQLStudio

五、免安装（Portable）版
  · 双击 MySQLStudio-2.0.0-portable-x64.exe 直接运行，无需安装、不写注册表、不建快捷方式
  · 程序会解包到 %TEMP%\MySQLStudio-2.0.0（约 540MB），同一版本再次启动直接复用，退出不删除
  · 连接配置仍保存在 %APPDATA%\MySQLStudio\connections.json，与安装版共用
  · 可把 exe 复制到 U 盘或任意目录使用
  · 卸载：关闭程序后删除该 exe，再删除 %TEMP%\MySQLStudio-2.0.0 目录即可
  · 首次启动同样会遇到 SmartScreen 提示（未签名），点「更多信息 → 仍要运行」

六、常见问题
  · 连接失败：确认 MySQL 服务已启动、端口（默认 3306）可达；
    远程连接需在 MySQL 中授权该用户从对应主机登录
  · 界面字体发虚：系统显示缩放 125%/150% 下建议使用默认缩放，
    或在「兼容性 → 更改高 DPI 设置」中勾选「替代高 DPI 缩放行为（系统）」
  · 杀毒软件误报：NSIS 安装包未签名时个别引擎会误报，添加信任即可
